# Security and privacy

Please do not attach real patient reports, personal health information, credentials, or restricted datasets to a public issue or pull request.

For a security or privacy vulnerability, use GitHub's private vulnerability reporting for this repository. If that option is unavailable, contact the repository owner through a private GitHub message before sharing details publicly.

The report explorer is designed to read PDFs in the browser without sending the file to a server. The public catalogue must omit restricted numerical GLOBOCAN values. Changes to either boundary deserve explicit review.
